# Handoff · agents-cli · 2026-09-10

## What this is
Go CLI + Slack bot that runs coding agents (Claude Code, Codex) on the user's own EC2 box via herdr. Repo: github.com/Achno2k/agents-cli (personal account, ssh alias `github-personal`, local git identity Achno2k). Read PLAN.md (decisions, box layout) and CLAUDE.md (parallel-session rules) first.

## Started with
An empty dir and a rough idea. Architecture was agreed, then v1 was built in one day by 7 parallel herdr sessions, each owning one package. Since then: iterative fixes from real runs against the user's EC2 (`ubuntu@ec2-13-50-242-118.eu-north-1.compute.amazonaws.com`, key `~/.ssh/agent-server-key.pem`, instance in the user's laptop config at `~/.agents/config.toml`).

## Current state (all pushed to main)
Working end to end on the real box: `agents init` (AWS profile picker or `aws configure` if none, instance picker, ssh, bootstrap, Claude login, GitHub auth via fine-grained or classic token or browser, clone, env plan generated by Claude and replayed, Slack tokens validated, bot under systemd). Slack bot receives mentions, creates a worktree + herdr pane + Claude session, posts status. Claude on the box runs unattended (`harness_args` default `--dangerously-skip-permissions`, worktree pre-trusted, onboarding and bypass-acceptance flags set post-login).

Commands: init, env, ssh, attach, sessions, bot, doctor, deploy, reset, version, hidden ui-demo.

UI: purple accent, orange loader and warnings, green/red status, Vercel-style `?`/`>` glyphs, ● / ○ selectors, collapsed answered prompts, step timings, nested phases with one live renderer, "Machine ready" block, AGENTS glitch banner with purple→orange gradient at start of init only.

## Conventions the user set
- Delegated sessions: Opus 5 only, never Fable. Keep session count minimal. Reuse idle panes.
- Lead (this role) gates `gofmt -l . && go build ./... && go vet ./... && go test ./...` before every commit, commits and pushes; delegated sessions never commit.
- Ship to laptop with `make install` (rm+cp, plain `cp` over the binary SIGKILLs on macOS). Ship to box with `agents deploy` (build, upload if sha changed, sync config, restart bot). Don't deploy while a Slack session is mid-run: it restarts the bot.
- User wants extremely concise replies, points not paragraphs.
- Auto mode classifier blocks writing bypass-permission flags; user switches out of auto mode when needed.
